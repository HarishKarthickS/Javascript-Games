# Javascript Games

Small browser games in JavaScript, kept as a learning folder — not a product.

Includes Frogger, Rock Paper Scissors, Breakout, Connect Four, Memory, Space Invaders, and Whac-a-Mole. Several directories still use tutorial-origin names (`Frogger-master`, `space-invaders-master`, `connect-four-master`); those copies follow Ania Kubow walkthroughs.

Open a game folder and load `index.html` in a browser (Rock Paper Scissors uses `Game.html`).
